# 🛍️ MallMate – Smart Mall Assistant

MallMate is a simple, responsive website that helps shoppers find stores, floors and facilities inside a mall. Built with HTML, CSS and JavaScript.

## 🌟 Features

- Mall search
- Store directory
- Interactive mall map
- Food and dining
- Shopping planner checklist
- Parking assistant
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 How to Run

1. Clone this repository:
2. git clone https://github.com/Kumud137/mall-mate.git

2. Open the project folder.
3. Open `index.html` in any browser.
